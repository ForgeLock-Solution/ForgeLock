# Plan de proyecto — por completar tras debate

## Objetivo y alcance
Pendiente.

## Etapas y puertas de aprobación
1. Descubrimiento: objetivos, necesidades y datos faltantes.
2. Arquitectura: debate documentado, decisiones de hosting, dominio y tecnología.
3. Diseño: estructura y propuesta visual para aprobación.
4. Desarrollo: componentes, contenido, integraciones autorizadas.
5. QA: pruebas y correcciones, checklist de entrega.
6. Prepublicación: aprobación de contenido, privacidad, dominio y accesos.
7. Publicación: **solo con autorización explícita**.
8. Entrega: documentación, titularidad, mantenimiento y pendientes.

## Riesgos y bloqueos
Por definir en comité.
